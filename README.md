# Network Blackout Analyzer — Vercel Deployment

Deploy the interactive **NET-BLACKOUT NOC v5.2** dashboard for free on Vercel or GitHub Pages in under 2 minutes.

## Option 1: Drag & Drop Deploy via Vercel CLI / Web (Instant)
1. Go to [vercel.com](https://vercel.com) and log in.
2. Click **Add New...** -> **Project**.
3. Import your GitHub repository, or run in this directory:
   ```bash
   npx vercel
   ```

## Option 2: Deploy to GitHub Pages (100% Free)
1. Push this folder to a GitHub repository.
2. Go to repository **Settings** -> **Pages**.
3. Under **Branch**, select `main` / `root` and click **Save**.
4. Your site will be live at `https://<username>.github.io/<repo-name>/`.
